## Overview

The **Pranava-Music Therapy Lab** website is the official digital presence of a research initiative founded at the **Indian Institute of Technology, Kharagpur**. The project bridges the scientific credibility of psychological research with the profound healing power of Indian classical and folk music. This platform serves researchers, practitioners, students, and the general public seeking evidence-based music therapy resources, event information, and team details.

The website is built as a modern, responsive single-page application using React 19 and Vite 8, with a carefully crafted editorial design aesthetic inspired by institutional research portals. It features smooth animations, accessible navigation, SEO best practices, and a clean, premium design language.

## Project Background

Pranava-Music Therapy Lab is a formally constituted research and outreach initiative at IIT Kharagpur. The lab explores the intersection of Indian classical and folk arts, cognitive neuroscience, and evidence-based mental health practices. Through structured research, expert mentorship, community outreach, and international dialogue, the lab seeks to make music-based wellness accessible to individuals experiencing anxiety, stress, loneliness, and emotional trauma.

The lab operates from **The Academy of Classical and Folk Arts, IIT Kharagpur, West Bengal, India**, under the leadership of its Principal Investigator and a multidisciplinary advisory body drawn from IIT Kharagpur and partner institutions.

## Design System

The website uses a unified design token system defined in `src/index.css` and registered with the Tailwind CSS v4 `@theme` directive.

### Color Palette

| Token | Hex Value | Usage |
|---|---|---|
| `--color-bg` | `#F8F8F6` | Page background |
| `--color-surface` | `#FFFFFF` | Card and modal surfaces |
| `--color-primary-accent` | `#3B6E6A` | Buttons, active states, borders |
| `--color-secondary-accent` | `#CA8A04` | Eyebrow text, badges, highlights |
| `--color-primary-text` | `#222222` | Headings and body text |
| `--color-secondary-text` | `#666666` | Captions and supporting text |
| `--color-border` | `#E5E5E5` | Card and input borders |
| `--color-divider` | `#ECECEC` | Section dividers |
| `--color-hover-accent` | `#2E5552` | Hover state for primary accent |

### Typography

| Type | Font | Fallback |
|---|---|---|
| Headings | Playfair Display | Georgia, serif |
| Body and UI | Inter | system-ui, sans-serif |

Both typefaces are loaded via Google Fonts and registered as CSS variables.

## Getting Started

### Prerequisites

Ensure that the following are installed on your system:

- **Node.js** version 18 or later
- **npm** version 9 or later

### Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd project
npm install
```

### Running the Development Server

Start the Vite development server with hot module replacement:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` by default.

### Building for Production

Generate an optimized production bundle:

```bash
npm run build
```

The compiled output will be placed in the `dist/` directory, ready for deployment to any static hosting provider such as Vercel, Netlify, or GitHub Pages.

### Previewing the Production Build

To locally preview the production build before deployment:

```bash
npm run preview
```
